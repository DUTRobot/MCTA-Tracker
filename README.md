Anticipated Release: [05, 2026]

🔭 Overview

This repository will contain the implementation of our research on distributed UAV swarm cooperative tracking systems. The code implements a novel framework where multiple quadrotor UAVs exchange target positions, trajectories, and coarse grid maps via UDP to collaboratively predict and track dynamic targets using a topology-based diffusion algorithm.

🛠️ What to Expect

Fully distributed swarm coordination without a central node ﻿ Real-time multi-UAV communication and decision-making ﻿ Rviz simulation environment with example launch files ﻿ Documentation including setup instructions, and example scenarios
